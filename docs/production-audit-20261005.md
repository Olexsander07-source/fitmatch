# FitGoIn: анализ повторного сбоя и исправление, 5 октября 2026

Сайт восстановлен по прежнему адресу **https://fitgoin.com/**. Ниже отделены проверки опубликованного сайта от сценариев с тестовыми ответами и незавершённой приёмки внешних сервисов.

## Причина повторного отказа

Production снова содержал только index.html, fitmatch.js и styles.css. Импортируемые модули fitgoin-premium.js, fitgoin-premium-core.mjs, fitgoin-i18n.mjs, дополнительные CSS, изображения и release.json возвращали HTTP 404.

Отсутствующий ES-модуль блокировал выполнение главного модуля до установки обработчиков кнопок. На свежей странице 390 px обработчики входа и паузы фона отсутствовали. Это одновременно объясняло неработающие кнопки и неподвижный фон.

Повторение вызвал второй издатель — **Cloudflare Workers Builds** старого Worker fitgoin. После изменения main он заменял полный сайт неполной сборкой. Проверка перед последним Git push не обнаруживала последующее повреждение.

## Исправления

1. Сборка заново собирает полный разрешённый набор и создаёт уникальный release.json с commit, временем и build ID.
2. Custom build запускает проверки исходников и полную сборку перед штатным Wrangler upload. Добавлен регрессионный прогон из папки с тремя файлами.
3. Production размещён в отдельном Worker fitgoin-production в том же аккаунте. Автоматический издатель остаётся привязан к старому fitgoin.
4. Общая конфигурация Wrangler не содержит маршрутов домена. Производственный адрес подключает штатный safe-deploy.mjs после публикации проверенной версии.
5. Первый выпуск нового Worker выполняется внутри штатного сценария после проверок и dry run, без публичных маршрутов. Только конкретный 404 разрешает инициализацию; ошибка доступа не считается отсутствием Worker.
6. Сценарий загружает версию, извлекает точный Version ID и активирует её на 100%.
7. workers.dev и preview-адреса выключаются и проверяются до подключения домена.
8. Домен переносится атомарно через endpoint Wrangler. Общий domains PUT возвращал 409 для уже существующей привязки. Проверяется changeset: только fitgoin.com и его зона, без удаления других доменов и конфликтов DNS. DNS и сертификат не удаляются.
9. После публикации сверяются HTTP-статус, тип содержимого и SHA-256 **всех 29 публичных файлов**. Ответа 200 у главной страницы недостаточно.

Сохранены требования проекта: чистая main, совпадение с origin/main, проверки и dry run, публикация через npm.cmd run deploy. Изменения прошли GitHub CI.

- «Стать тренером» открывает регистрацию тренера с правильной ролью.

- Логотип возвращает на главную.
- Настройки cookies открываются, выбор сохраняется.
- Горизонтального переполнения нет.
- Фон автоматически меняется; пауза удерживает его минимум 9 секунд, возобновление запускает смену.
- Ошибок JavaScript и неуспешных собственных запросов нет.

Отдельно прошла эмуляция сенсорного телефона 390 × 844 px: touch-нажатия регистрации и входа; начальная пауза при reduced motion и ручное включение фона. Это Chrome с мобильной эмуляцией; физический iPhone/Safari не проверялся.

## Исходники и остальные сценарии
