# FitGoIn AI — подготовка к выпуску

Дата: 4 октября 2026. Доработки сохранены в существующем PR №14. По последнему указанию сейчас завершается подготовка; полная проверка реальных AI-ответов и платежей, затем публикация — следующий этап. Существующий сайт не перестраивается.

## Что сейчас препятствует выпуску

OpenAI отклонил реальный запрос: HTTP 429, `credit_balance_exhausted`. В организации нет доступных предоплаченных API-кредитов. Наличие ключа не подтверждает возможность получать ответы. Повторные запросы не восстановят баланс. Подробности: [официальная документация OpenAI](https://developers.openai.com/api/docs/guides/error-codes).

В доступном Stripe sandbox пока нет активных Prices и webhook endpoints. Приём оплаты отключён. Подключение одного ключа OpenAI не включает подписки.

## Порядок следующего этапа

1. Восстановить баланс OpenAI API. Секретный ключ уже подключён; повторно присылать его не нужно.
2. Проверить настоящие ответы: тренировочная программа и её длительность, адаптация по усталости, питание и исключения, вопросы при неполном профиле, осторожность при боли и для несовершеннолетних, источники поиска, распознавание речи, неопределённость оценок фото и выбранных кадров, языки, скорость и расход бюджета. Не заменять эти проверки тестовыми ответами.
3. Подготовить Stripe sandbox: отдельный ограниченный ключ, три отдельных месячных тарифа в EUR (тренировки €20, питание €10, пакет €30), подписанный webhook и согласованный тестовый режим обеих серверных функций. Точные серверные настройки описаны в `supabase/functions/fitgoin-ai/README.md`. Секреты сохраняются в Supabase, а не в коде или переписке.
4. Проверить цепочку оплаты: Checkout → подписанное событие → доступ; затем продление, сбой оплаты, отмену, возврат, спор, Portal и одновременные попытки покупки. Проверить, что тестовая подписка не открывает рабочий доступ.
5. Перед реальным приёмом денег подтвердить готовность продавца, условия подписки, отмены и возвраты, налоговые настройки. Stripe Tax включать после проверки соответствующей регистрации. Учесть существующее предупреждение Supabase об отключённой защите от утекших паролей.
6. После успешной приёмки сохранить окончательные изменения, объединить PR №14 и выполнить существующий безопасный выпуск из чистой `main`, совпадающей с `origin/main`: `npm.cmd run check`, `npm.cmd run deploy:dry`, затем `npm.cmd run deploy`. Проверить опубликованный интерфейс и основной сценарий на fitgoin.com. Прямой обход `scripts/safe-deploy.mjs` не использовать.

## Границы результата

Подготовлен кандидат для полной проверки. Успешные реальные AI-ответы и платежи пока не подтверждены; новый интерфейс не опубликован. Анализ видео работает по выбранным кадрам. Напоминания добавляются через импорт календаря. Оценки еды и техники остаются приблизительными; результат не является медицинской проверкой.
